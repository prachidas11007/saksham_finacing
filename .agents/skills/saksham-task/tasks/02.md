1. src/constants/theme.ts: navy / white / teal palette with named colours (background, surface, text, mutedText, primary, onPrimary, accent, success, warning, danger, border), spacing scale, radii, font sizes (caption, body, title, heading). Text on background contrast at least 4.5:1.
2. src/constants/limits.ts: MIN_TOUCH_DP=48, SIMPLE_TOUCH_DP=56, LARGE_TEXT_SCALE=1.25, MAX_FONT_MULTIPLIER=1.4, MAX_AMOUNT=100000000, MAX_NOTE_LENGTH=100, BUDGET_WARNING_PERCENT=80, plus the D-12 EMI limits (principal, rate, tenure min and max).
3. src/context/PreferencesContext.tsx: IN-MEMORY only: {simpleMode:false, largeText:false}, setters, usePreferences(). Wrap the root layout. (Task 4 adds storage.)
4. src/components, one per file:
 - AppText: variants caption/body/title/heading; Large Text multiplier (D-11); wraps.
 - AppButton: primary/secondary/danger; optional @expo/vector-icons icon; always a visible label; min height 48 (56 in Simple Mode); fullWidth option; accessibilityRole="button".
 - Card; ScreenContainer (safe-area insets, optional scroll, padding, keyboard-safe option); EmptyState (icon, title, message, optional action).
 - AppInput: label, hint, error, keyboardType, multiline, maxLength.
 - ProgressBar: value 0-100 plus a text slot so the percent is also words.
 - Banner: info/warning/danger/success, always icon + text.
5. Components take all text through props; none of their own.
