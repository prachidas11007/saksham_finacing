# Task 10: My Money, transactions (PRD 6.4, 7.2; FR-18, FR-19, FR-23; D-07, D-13 to D-15, D-17, D-23)
Install: `npx expo install @react-native-community/datetimepicker`
1. my-money.tsx: three sections switched by labelled buttons: Transactions, Budgets, Goals (Budgets and Goals = EmptyState for now). Transactions: summary card for the viewed month (default current) with Income, Expenses, Net tracked amount, and the note "Tracked demo amount. Not your bank balance." Then a FlatList newest first by date, then createdAt. Row: translated category label, note, formatINR amount, date, delete button (icon + label + accessibilityLabel).
2. Month arrows are optional: build them LAST and only if all else works.
3. transaction/add.tsx: Income/Expense toggle; amount (AppInput, decimal-pad, parseAmount); category chips (D-07 keys for the type, translated labels); date (default todayLocal(); "Change date" opens the datetimepicker; save with toLocalDateString); optional note (max 100, with the translated "Do not type bank details here" under it). Save disabled until valid. Errors use the Task 5 translated messages. After saving go back to the list.
4. Delete: translated confirmation Alert, then deleteTransaction.
5. All totals from useMonthSummary. No maths in the screen.
6. Empty state explains how to add the first demo entry; never calls numbers a balance.
Run: `npm run verify`, `npx expo export --platform android`.
