# Task 5: Languages, first-launch gate, check scripts (PRD 8, FR-01 to FR-05; D-04, D-13, D-18)
Install: `npm install i18next react-i18next`. Read the CURRENT i18next docs for synchronous init with bundled resources (option names changed between versions). No Suspense.
1. src/i18n/index.ts: bundled en, hi, mr; fallbackLng 'en'; escapeValue false; initialised before first render. Export tList(key): string[] using Array.isArray (else return [] and warn in dev).
2. src/i18n/locales/{en,hi,mr}.json with groups: common (app name, Save, Cancel, Back, Delete, Yes, OK, Loading, offline message, "External official website, needs internet"), languages, tabs (home, myMoney, learn, access, profile), errors (one per parseAmount reason + generic), disclaimer (student prototype, not a bank, tracked demo amount, not connected to your bank), a11y.
3. When PreferencesContext.language changes call i18n.changeLanguage (instant, no restart).
4. Root layout: keep splash up (expo-splash-screen) until Preferences are ready, hide once. src/app/index.tsx: language null -> <Redirect href="/language" />, else <Redirect href="/(tabs)/home" />.
5. src/app/language.tsx: three large cards English, हिंदी, मराठी (native names from a constants file). Nothing pre-selected. Tap saves language and uses router.replace to home (back button must not return).
6. Minimal tabs: src/app/(tabs)/_layout.tsx + home.tsx with a translated welcome line and current language name. Delete the Task 2 TEMP-DEMO screen.
7. Node scripts (Windows/Mac/Linux):
 - scripts/check-i18n.js: flatten keys of the 3 files. FAIL on key mismatch, array length mismatch, empty value; print exact missing keys. WARN (not fail) if a hi/mr string over 20 chars equals the English.
 - scripts/scan-hardcoded.js: scan src, skipping src/i18n, src/constants/theme.ts, tests, TEMP-DEMO files. FAIL on: text directly inside JSX; placeholder/title/label/accessibilityLabel holding a plain string; hex colours; fontSize numbers; the ₹ sign; 'http' or 'tel:' outside src/data/officialLinks.ts; empty catch; toISOString(. Print file and line.
 - package.json: "check:i18n", "scan", "verify": "npm run typecheck && npm test && npm run check:i18n && npm run scan".
Run: `npm run verify`, `npx expo export --platform android`.
