# Task 9: Learn, Read Aloud, Quiz (PRD 6.3, 7.2; FR-13 to FR-16; D-04, D-09, D-10, D-19)
Install: `npx expo install expo-speech`
1. src/data/lessons.ts: six lessons banking, savings, upi, fraud, borrowing, help (icon + key prefix only). Text in en, hi, mr under lessons.<id>: title, summary, paragraphs (4-6 short, one idea per sentence), takeaways (3-4). Topics: basic banking; savings; UPI basics; digital fraud prevention; borrowing and interest; complaints and help. Explain interest, EMI, UPI PIN, KYC, Bank Mitra simply. D-19: no numbers, no promises.
2. src/data/quizzes.ts: quiz 'core', 5 questions: option count + correctIndex (NOT translated). Text, options, explanation under quiz.core.q1..q5. One question: can anyone ask for your UPI PIN or OTP? (never share).
3. learn.tsx: six cards; completion as icon AND the word "Completed"; plus a quiz card showing the best score.
4. lesson/[id].tsx: title, paragraphs, takeaways; buttons Read Aloud / Stop, Mark complete, Start quiz. Simple Mode: summary + takeaways first, paragraphs behind "Show more".
5. src/utils/speech.ts: speakText(text, languageCode) mapping en->en-IN, hi->hi-IN, mr->mr-IN. First call Speech.getAvailableVoicesAsync() and check a voice exists; if not return 'noVoice' and the screen shows a friendly translated message (text stays readable). Split long text into chunks under Speech.maxSpeechInputLength. Add stopSpeech(). Track speaking via onDone, onStopped, onError.
6. Stop speech on leaving the screen (unmount and blur) and on language change.
7. quiz/[id].tsx: one question at a time; pick an option; Submit (disabled after first press so double tap counts once); Correct / Not correct as icon AND words + explanation; Next; final score via scoreQuiz; Retry. Save with saveQuizResult.
Run: `npm run verify`, `npx expo export --platform android`.
