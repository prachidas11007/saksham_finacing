Install: `npx expo install @react-native-community/netinfo`
1. src/data/officialLinks.ts is the ONLY place for URLs and the helpline. Each link: id, url, labelKey, lastReviewedAt ('2026-11-13'). Use exactly these, add or change none:
 pmjdy https://www.pmjdy.gov.in/scheme ; rbiEducation https://www.rbi.org.in/financialeducation/ ; rbiFame https://www.rbi.org.in/FinancialEducation/fame.aspx ; npciFraud https://www.npci.org.in/fraud-awareness ; npciUpiFaq https://www.npci.org.in/what-we-do/upi/faqs ; cybercrime https://cybercrime.gov.in/ ; rbiComplaints https://www.rbi.org.in/Scripts/Complaints.aspx ; rbiCms https://cms.rbi.org.in/ ; janSuraksha https://jansuraksha.gov.in . 2. src/data/accessGuides.ts: five guides bank-account, digital-payments, borrowing, savings-protection, help. Each: id, icon name, translation key prefix, linkIds. 'help' opens /safety-help (placeholder until Task 8).
3. Content in en, hi, mr under guides.<id>: title, summary, whoItHelps, steps (4-6 short ordered), questions (3-5 to ask an authorised provider), caution.
 - bank-account: visit a branch or authorised Bank Mitra; ask about the current account type, KYC documents, charges, features; get details in writing; PMJDY is an official scheme option to ASK about, not a guaranteed right.
 - digital-payments: what UPI is in simple words; never share UPI PIN or OTP; PIN is only for paying, never for receiving; no unknown QR codes, reward or refund links, unknown apps or screen sharing.
 - borrowing: explain lender, principal, interest rate, fees, tenure, EMI, total repayment, late fees, collateral simply; check the lender is authorised; compare total cost; never pay an agent for guaranteed approval; link to /calculator (built in Task 12).
 - savings-protection: what saving, insurance, pension mean simply; ask your bank about government-backed options; official link janSuraksha.
 Obey D-19: no amounts, ages, fees, rates, promises.
4. Screens: replace access.tsx placeholder (large labelled cards, icon + text); create access/[topic].tsx (summary, who it helps, ordered steps, questions, caution, a Banner "Verify current terms with your bank or provider" on EVERY guide, official link buttons).
5. src/components/ExternalLinkButton.tsx: shows "External official website, needs internet" and the lastReviewedAt date (D-20). On press check NetInfo. Offline: translated "Internet needed to open this link", nothing else. Online: Linking.openURL in try/catch with a translated error.
6. All guide content works offline. No text inputs.
